# Dola Studio 1.0.1

本次统一当前源码的产品命名与版本，未部署或重启线上服务。

## 版本与名称

- 服务端 `APP_VERSION`、FastAPI 版本、健康接口与面板更新信息统一为 `1.0.1`。
- 前端 manifest、页面内本地资源的缓存版本和 Chromium 扩展版本统一为 `1.0.1`。模型、协议、第三方依赖及历史验收版本保持其真实含义。
- 当前源码、文档、测试和部署模板使用 Dola Studio / `dola-studio` 命名；安装与更新脚本的默认仓库为 `sailsships/dola-studio`。
- 原始 MIT 版权与许可保留，第三方准确来源可经 [来源说明](../THIRD_PARTY_NOTICES.md)中的不可变历史链接追溯。未重写 Git 历史。

## 数据与配置兼容

账号数据库使用 `DOLA_ACCOUNT_DB_PATH`。原配置键仍可读取；同时提供新旧键时，新键优先。源码默认文件仍为 `pool_usage.db`，不因改名切换数据文件。

Docker 入口先读取新旧键，再应用 `/data/pool_usage.db` 默认值，避免镜像内置的新键默认值盖过已有账号库路径。此处验证了路径选择逻辑，尚未完成 Docker 镜像构建验收。

新 Cookie 导出标识为 `dola-studio-cookies-v1`，批量文件名为 `dola-studio-cookies.zip`。账号名、Cookie 值、域及路径等字段保持不变；历史格式包装仍能导入。

历史验收记录中的备份根目录已明确脱敏，保留备份 basename 与原始记录链接。这不是生产目录迁移；恢复必须使用原始记录中的完整路径。
