超分接入说明

在「设置 → 视频超分」开启总开关并保存后，任务和视频页才显示超分操作。关闭后不接受新的超分任务；已经受理的任务继续查询，已有高清结果可继续下载。

配置与费用

服务可选 fal、自建服务或自定义 API。密钥不填写表示不修改，清空表示删除。外部服务可能计费，请以服务商当前价格为准。超分处理已完成原片，不改变生成时长。

自建服务

POST {base_url}/v1/upscale
{"video_url":"https://example.test/source.mp4","target_resolution":"1080p","fps":null}

GET {base_url}/v1/upscale/{id}

提交返回任务 id；查询返回 status 和 video_url，失败返回 error。有令牌时发送 Authorization: Bearer 令牌。原片地址必须能被服务端访问。

自定义 API 模板

填写实际提交 URL、JSON 请求头、请求体模板、任务 ID 路径和查询 URL。可用占位符：{{video_url}}、{{target}}、{{duration}}、{{task_id}}；查询 URL 使用 {{id}}。路径使用点号，数组如 data.result.0。任务 ID 路径留空表示同步接口。

配置成功状态值、失败状态值、结果 URL 路径和错误路径。先核对供应商响应，不能只根据 HTTP 200 判断成功。

管理 API

GET /api/admin/settings/upscale
PATCH /api/admin/settings/upscale
POST /api/admin/tasks/{id}/upscale

以上路径需要管理员身份。首次使用默认关闭；总开关关闭时提交返回 409。配置必须保存成功才在前端生效。
