构建与发布说明

本部署为 Dola Studio 定制构建，管理 Dola / 豆包账号、代理与视频任务。API 路径和现有配置字段保持兼容。

模块结构

控制台按请求层、导航与设置、账号、代理、任务、视频、生成表单等职责拆分。后台刷新只同步变化的数据，前台交互状态保留。

更新方式

默认不自动安装其他仓库的版本，以免覆盖定制功能。管理员可在部署环境中显式设置 DOLA_UPDATE_REPO=owner/repository；只有受信任且兼容的发布仓库才能使用，现有外部更新程序仍需另外安装和验证。

重构边界

重写请求协调和状态投影，模块化控制台。生成协议、签名与账号兼容实现保留，不宣称全部源码独立原创。MIT 版权和第三方许可随源码包保留。

操作说明

连接地址、密钥和模型参数请在侧栏「API 调试」中填写。超分默认关闭。
