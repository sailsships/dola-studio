完整接入说明
参数、流程、网站接入与排错

    
第一步：网站地址、API 地址和 Key 分别填什么？

      
调用方网站是客户访问的前台，例如 https://www.example.com；API 服务地址是这套管理软件部署的地址，例如 https://api.example.com，两者可以不同。填网站地址只是记录接入环境，不会自动配置 DNS、回调、CORS 或反向代理。

      
根地址填写 https://api.example.com；某些工具要求 OpenAI Base URL，填写 https://api.example.com/v1。调试器会把末尾重复的 /v1 去掉，再拼接完整路径。部署在子路径时填写 https://example.com/studio，接口为 /studio/v1/…。

      
API Key在左侧“API 密钥”中创建并复制，请求头为 Authorization: Bearer YOUR_API_KEY。不要填写面板密码、Cookie 或上游平台 Key。模型列表可以匿名读取；它成功不代表鉴权和生成可用，最终以实际请求及任务状态为准。

      
保存模板只保存在当前网站、当前浏览器。换浏览器或给另一台机器使用时，导出 JSON 再导入；导出的模板和说明都不包含真实 Key，需要在目标环境单独填写。

    

    
第二步：选择 Dola 或豆包，以及聊天 / 工作模式

      
seedance-2.0-fast、seedance-2.5路由到 Dola；doubao-seedance-*路由到豆包视频账号；doubao-seedream-*路由到豆包生图账号。模型名决定平台，不能把豆包模型名改写为 Dola 模型名来通用调用。

      
聊天模式传 execution_mode: "chat"，工作模式传 execution_mode: "work"。Seedance 2.0 Fast 的两种模式均可配置 15 秒；最终还受账号能力、额度及 Key 允许时长限制。部分豆包账号只适用个人聊天或工作空间，选项必须与账号类型相符。

      
本模板默认只提供 5 / 10 / 15 秒，以单条视频接入为主。不同模型支持的档位可能不同；以服务端校验和账号能力为准。30 秒与双视频需要额外部署能力和额度，不能仅修改时长获得支持。模型清单代表接口已识别的模型，不保证池中有对应的可用账号。

    

    
第三步：视频异步流程与返回字段

      
  1. POST /v1/videos/generations，提交 UTF-8 JSON，保存返回的 id。兼容入口 /v1/videos使用相同逻辑，成功返回 HTTP 202。
  2. 每隔 5～10 秒 GET /v1/videos/{id}。需要使用创建任务时的客户 Key；不同 Key 不能查询彼此的任务。
  3. queued为排队，processing为处理中，completed才代表完成，failed查看 error。进度说明在 progress，最终视频在 video_url；多视频结果可能在 videos，高清结果可能在 video_url_hd。
  4. 保存最终结果；可用 GET /v1/videos/{id}/content读取完成视频。视频地址可能有过期时间或保留期限，长久保存请及时下载。

      
如果创建请求超时且未收到 ID，结果可能不确定。先在任务列表按时间和提示词核对，不要立即重复 POST；本接口没有公开的幂等键保证。调试器不会自动轮询或自动重发，点击“使用返回 ID 查询”可以继续手动查询。

    

    
视频、图片与 Ark 接口速查
方法与路径用途说明

      
GET /v1/models模型列表当前公开读取；不验证 Key
POST /v1/videos/generations创建视频JSON 或 multipart；异步返回任务 ID
POST /v1/videos兼容视频入口相同生成逻辑，HTTP 202
GET /v1/videos/{id}查询视频需使用创建时的 Key
GET /v1/videos/{id}/content读取完成视频视频流或重定向，适合下载
POST /v1/images/generations豆包生图同步返回 data 数组，含图片 url
POST /v1/images/edits豆包改图JSON 参考图或 multipart 文件
POST /api/v3/contents/generations/tasksArk 创建视频content 数组，异步任务
GET /api/v3/contents/generations/tasks/{id}Ark 查询视频queued / running / succeeded / failed

    
Ark 还兼容 /v1/video/contents/generations/tasks 和 /v1/contents/generations/tasks。这套服务提供视频 / 图片接口，并不等同于通用文字聊天接口；工具只支持 /v1/chat/completions 时，需要在工具侧选择视频插件或视频提供商。

    
请求参数：哪些必填，哪些可按需修改？
字段类型 / 示例用途与限制

      
modelstring建议显式指定；Dola、豆包视频与图片模型不同
promptstring非空 UTF-8 描述，不要用乱码或问号替换中文
execution_modechat / work视频模式；图片请求不需要此字段
duration整数，例如 15视频秒数；兼容 seconds / duration_seconds，优先 duration
ratio16:9 / 9:16 / 1:1画面比例；size 可按接口要求提供尺寸
video_count1，部分能力支持 2模板固定单条；双条取决于模型、模式与部署配置
reference_imagesURL 字符串数组图生视频 / 图生图，支持公网可读取 URL 或 data URL
reference_audioURL 字符串数组受模型和模式限制；Seedance 2.0 Fast 聊天 15 秒可用，工作模式不支持
reference_sourceunspecified / ai_generated根据素材真实来源填写；不影响认证
resolution720p / 1080p / 2k / 4k视频原片或自动超分配置；写分辨率不等于已开启高清能力
n1～4图片张数，不是视频条数；还取决于上游能力
response_formaturl / b64_json图片响应格式，默认 url

    
Ark 创建请求把提示词放在 content: [{"type":"text","text":"…"}] 中；参考图可使用 {"type":"image_url","image_url":{"url":"https://…"}}。直接编辑右上 JSON 后可调试参考素材；模板参数变化会重建请求体。

    
接入自己的网站、画布或第三方工具

      
网站后台调用：前端把用户输入交给自己的网站后台，后台从环境变量读取客户 Key 并调用这里的 API，返回任务 ID 给前端；前端向自己的后台查询结果。提供的 Node.js / Python 示例可作为后台调用模块。不要把公共网站的服务器 Key 写入前端源码、HTML 或公开仓库。

      
画布 / New API：若配置项叫“服务地址”，填写根地址；若明确叫 OpenAI Base URL，通常填写根地址加 /v1。视频入口选择 /v1/videos/generations 或 /v1/videos，模型填写本页模型列表中的原始 ID，Key 填客户 Key。路径拼接方式由工具决定，以工具实际发出的请求为准。

      
浏览器直接调试：本页请求直接从浏览器发到填写的 API 地址。跨域时由目标服务允许当前页面来源的 CORS；HTTPS 页面访问 HTTP 服务可能被浏览器阻止。网站地址字段不能解除这些限制。遇到连接异常时可用生成的 cURL / 后台示例核对。

      
域名和反向代理：域名应解析到 API 服务并配置有效 HTTPS。代理需把 /v1 和 /api/v3 对应路径转发到这套服务，保留 Authorization 请求头；图片接口是同步返回，代理超时需要覆盖实际生图耗时。视频创建异步返回，不需要一直等到视频生成结束。

    

    
常见错误、重试与接入验收
现象检查方向

      
401Bearer 头、Key 内容、是否已停用或过期；不要用面板登录密码
403 / 429读取 detail；Key 配额、并发、时长权限、账号额度或平台限流；不要立即批量重试
404根地址、反向代理前缀、重复 /v1、任务 ID；查询时使用创建任务的 Key
422字段类型、模型名、时长、模式、素材格式与账号能力，以 detail 为准
502 / 503 / 504上游异常、无可用账号、超时；核对任务状态和代理后再决定是否重试
浏览器 Failed to fetchCORS、HTTPS / HTTP、DNS、证书或网络；不代表 Key 校验失败
HTTP 200 但不能解析可能返回了网站首页或代理错误页；检查最终 URL、路径和 Content-Type
有 ID 但没有视频任务仍在排队 / 处理中；查询到 completed / succeeded 后再读取视频地址

    
建议验收顺序：读取模型列表 → 核对客户 Key 和权限 → 只提交一条 5～15 秒视频 → 保存 ID → 查询最终状态 → 打开或下载结果 → 再逐步提高并发。模型读取不耗生成额度；点击 POST 生成会使用账号额度。创建请求超时不自动重发，查询请求可在短暂间隔后再次读取。
